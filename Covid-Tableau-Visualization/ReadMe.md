# COVID Dashboard

This dashboard visualizes global COVID-19 trends based on data explored in Part 1 of my portfolio project. It highlights deaths, infection rates, and vaccination trends across countries over the last 4 years.

## Key Visuals
- Line charts for total cases and deaths over time by country
- Bar chart showing % of population infected by country
- Horizontal bar chart of countries with highest death percentages
- Rolling vaccination totals per country
- Optional map showing % of population vaccinated

## Skills & Tools
- Tableau Desktop / Tableau Public
- Dashboard design and interactive filtering
- Connecting SQL views / datasets to dashboards
- Data visualization best practices

## Insights
- Enables comparison of infection and death trends across countries
- Visualizes vaccination progress over time
- Supports exploratory analysis and decision-making
