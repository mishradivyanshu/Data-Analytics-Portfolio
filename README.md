# Data Analytics Portfolio — Alex The Analyst Series

This portfolio contains a series of four projects that demonstrate a complete data analytics workflow, from raw data exploration to final visualization and insights. The focus is on clean, reproducible steps and practical, business-oriented thinking.

---

### **1. COVID Data Exploration (SQL)**
A foundational project using SQL to explore and understand the global COVID-19 pandemic.

- **Objective:** Use SQL to analyze key metrics like infection rates, death percentages, and vaccination trends.
- **Key Skills:** SQL fundamentals, advanced joins, window functions, CTEs, and creating reusable SQL views.
- **Repository:** [Link to your COVID SQL repo]

### **2. COVID Dashboard (Tableau)**
An interactive dashboard built to visualize the insights discovered in the SQL data exploration.

- **Objective:** Create a user-friendly and interactive dashboard to present COVID-19 data.
- **Key Skills:** Data visualization, KPI design, time-series analysis, and dashboard filtering.
- **Tableau Public:** [Link to your Tableau Public dashboard]

### **3. Nashville Housing Data Cleaning (SQL)**
A hands-on project focused on data cleaning and transformation using SQL.

- **Objective:** Take a raw dataset and clean it by handling missing values, standardizing formats, and removing duplicates.
- **Key Skills:** Data cleaning techniques, string manipulation (`SUBSTRING`, `PARSENAME`), conditional logic, and duplicate removal using `ROW_NUMBER()`.
- **Repository:** [Link to your Nashville Housing repo]

---

### **4. Movie Dataset EDA (Python)**
An exploratory data analysis project using Python to uncover insights into what makes a movie successful.

- **Objective:** Analyze a movie dataset to identify correlations and patterns related to box office success.
- **Key Skills:** Python (Pandas, Matplotlib, Seaborn), data cleaning, statistical analysis, and data visualization.
